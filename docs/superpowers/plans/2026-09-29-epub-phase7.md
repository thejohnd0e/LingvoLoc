# Phase 7 EPUB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add recoverable EPUB translation and package-preserving export to the existing desktop Documents workflow.

**Architecture:** Parse the EPUB container, OPF manifest, and spine in a dedicated `documents/epub` module. Reuse the existing `DocumentBlock`, store, worker, coordinator, diagnostics, and safe-export pipeline; rewrite only supported XHTML spine entries and raw-copy all other ZIP entries.

**Tech Stack:** Rust 2021, Tauri 2 commands, `zip` 2.4, `quick-xml` 0.42, SQLite/rusqlite, React/Vite/strict TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-29-epub-phase7-design.md`

## Global Constraints

- Implement EPUB only; do not begin FB2 or production PDF support.
- Preserve TXT and DOCX behavior, ordinary history, extension APIs, runtime settings, and global prompts.
- Process EPUB spine order, not ZIP or filename order.
- Never replace a source file or an existing output file.
- Preserve all untouched package entries, resources, ids, anchors, links, and styles.
- Reject unsafe/duplicate/encrypted/oversized archive entries and external XML/resource fetching.
- Use deterministic tests and run the full repository gates before declaring the phase complete.
