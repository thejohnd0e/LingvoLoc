# PDF Export Fonts

The PDF exporter uses the static Latin-Greek-Cyrillic Noto Sans and Noto Serif
families, release `v2.015`, from the official repository:

<https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015>
<https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSerif-v2.015>

The files are static TTF instances with Latin, Greek, and Cyrillic coverage.
They are redistributed under the SIL Open Font License 1.1; see `OFL.txt`.
